# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.0.x   | :white_check_mark: |
| < 2.0   | :x:                |

## Reporting a Vulnerability

The Borsel Handler team takes security vulnerabilities seriously.

If you discover a security vulnerability in Borsel Handler (such as credential exposure, SSRF in collector endpoints, formula injection in export handlers, or unauthorized API access), please report it responsibly:

1. **Do not create a public GitHub issue.**
2. Send an email to the project maintainer at `officialayush5839@gmail.com` with:
   - A clear description of the vulnerability.
   - Steps to reproduce or proof-of-concept script.
   - Potential impact.
3. You will receive an initial response within 48 hours.
4. We will coordinate a remediation release before public disclosure.
